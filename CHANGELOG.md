## 1.0.0

* Initial release of the `segmented_date_pickerc` package.
* Added `showSegmentedDatePicker` as a direct, drop-in replacement for Flutter's native `showDatePicker`.
* Implemented independent, smoothly animated panels for Year, Month, and Day selections.
* Added `SegmentedPickerColors` configuration for granular custom color overrides (accent, header, background, etc.) while preserving adaptive light/dark theme fallbacks.
* Designed a compact vertical footprint to prevent UI overflow issues when the keyboard opens in text-input mode.
* Ensured zero external dependencies for maximum performance and compatibility.
